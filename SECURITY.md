# Security Policy

## Supported Versions

Canonify is a static educational document archive and web application. We actively maintain and secure the current production release on GitHub Pages.

| Branch / Target | Supported          |
| :-------------- | :----------------- |
| `main`          | :white_check_mark: |
| Old Releases    | :x:                |

---

## Reporting a Vulnerability

If you discover a security vulnerability, privacy leak, or unintended sensitive data exposure in this repository:

1. **Do NOT open a public GitHub issue.**
2. Send an email to the project maintainer:
   - **Email:** `deekshithvodela@gmail.com`
   - **Subject:** `[SECURITY] Canonify Vulnerability Report`
3. Please include:
   - Description of the vulnerability or data concern
   - Steps to reproduce or specific file paths
   - Potential impact
4. You will receive an acknowledgment within 48 hours.

---

## Scope & Zero Secrets Policy

- Canonify is a static, client-side web application hosted on GitHub Pages.
- It does not process candidate passwords, login credentials, or payment transactions.
- All documents hosted in this repository are public domain government publications issued by the Medical Counselling Committee (MCC) and State Admissions Directorates.
- Candidate PII in government public merit lists remains in its original public domain format as published by the respective government authorities.
